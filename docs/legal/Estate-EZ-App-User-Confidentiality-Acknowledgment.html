User is being given access to Company’s internal software tools (including Estate-EZ / related mobile or web apps), workflows, and business information to help operate Company’s sales and listings. User agrees:

1. Confidential

The following are confidential and belong to Company:

  • existence, features, demos, screenshots, and results of the app/tools;
  • how listings, photos, pricing, invoices, shipping, or CT Seller workflows are done with the tools;
  • customer/sale photos, descriptions, prices, invoices, buyer info, and internal notes;
  • usernames, passwords, codes, links, and access to Company accounts/systems.

2. Do not talk about it outside this team

User will not discuss, demo, show, screenshot, or describe the app or confidential workflows to anyone outside Company’s authorized team, including friends, family, social media, group chats, employees or owners of other franchises / other locations (including any Vegas location), vendors, buyers, or the public.

Casual talk like “we use an AI tool that posts listings / helps with shipping” is still a disclosure and is not allowed without Company’s written approval.

3. Dual-location / other franchise rule

If User also works at another franchise or location:

  1. User will not use Company’s app, logins, or confidential methods for that other location;
  2. User will not share the app, access, or know-how with that other location;
  3. User will not copy Magelda (or Company) data into systems used by the other location;
  4. Questions from the other location about the tool must be directed to Company ownership — User will not explain or demo it.

4. Allowed use only

User may use the app only for Company-authorized work. User will not:

  • share their login or use someone else’s;
  • download/export data for personal use;
  • reverse engineer or try to copy the product;
  • use Company tools to start or help a competing side project.

5. Return / end of access

When access ends (or upon request), User will stop using the app, delete any Company data from personal devices (unless Company says to retain something specific), and return any written materials.

6. How long this lasts

These duties start on the Effective Date and continue during access and for 3 years after access ends (longer for trade secrets, as allowed by law).

7. Breach

Unauthorized disclosure can harm Company. Company may revoke access immediately and pursue remedies allowed by law.

8. Acknowledgment

User has read this, understands it, and agrees to follow it. This does not by itself change employment status or create a promise of continued work.
