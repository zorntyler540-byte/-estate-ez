# Screenshots

Drop PNG/WebP captures here and they will render from the root README.

Suggested filenames (match the table in `README.md`):

- `dashboard.png` — sale dashboard with lots and catalog progress
- `lot-detail.png` — lot editor (title, description, photo gallery)
- `mobile-capture.png` — Expo field-capture camera or queue screen

Do not commit estate-sale photos that identify a real client, address, or unreleased auction.
